Installation

KissMyRank is not installed. Please follow the instructions below to install KissMyRank, or contact your Server Administrator:

  1. Download KissMyRank
  2. Extract the correct folder for your platform from the KissMyRank zip into a folder called "kissmyrank" (case sensitive) in your Assetto Corsa Server folder
  3. Make sure that you have set UDP Plugin Address and UDP Plugin Local Port in Server Options
  4. Refresh this page!
