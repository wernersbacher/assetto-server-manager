Global and per-server settings

Per server: server options (including the ports), sTracker, KissMyRank and Real Penalty options, blacklist, messages (MOTD), logs of the acServer, the current config, live timing and the race control, the running event and the last race.

Shared by all servers: accounts, the audit log, cars, tracks, weather and setups, the AutoFill entrants, penalties, the calendar and scheduled events, championships and their results (results are kept in the folder of the server that ran the session).

Notifications (Discord) are sent with the options of the default server, the Discord settings of the other servers are not used. ACPitwall log is shared, only the acServer log belongs to a server.
