Open Championship
Anyone can join an event while the Championship still has empty entrant slots; new entrants fill the slots. Slots can be edited (e.g. to assign teams) when editing the Championship.
On (the default): drivers who join are added to the Entry List. Off: every event starts with an empty Entry List, which suits many changing drivers. Results still persist to the Championship either way.
Sign Up Form
Anyone can register on a Sign Up page to be added to the Entry List.
An admin/write user accepts or rejects every application on a separate page.
Lets you contact drivers with event details.
Drivers can specify their team.
Teams are created on the Teams page. Only "Ask for team" decides whether the team is asked at all.
Drivers one team can register: 0 is the default of 2, -1 is unlimited. Only an admin/write user can change a team after registration.

Dropped Results
Number of worst event results dropped from each driver's (and team's) total; 0 drops nothing. Only completed events count, a missed event counts as 0 points (dropped first), at least one result always counts and points penalties are never dropped.

Championship Race Settings
Fuel, damage, tyre wear, assists and dynamic track are set once for all events that use the Championship race settings (the default for new events); changing them here changes all of those events. Events can opt out in their own configuration. Track, cars, sessions and weather are still set per event. {{ if not $f.HasRaceSettings }}The values below are prefilled from your latest event.{{ end }}
Race Values
Assists

At the start of the session or after a pitstop, tyres will have the the optimal temperature.
Realism

Force clients to use Virtual Mirrors (does not work in VR)
Fuel usage multiplier in percent: 0 = no fuel usage, 100 = realistic, higher values increase usage
Damage from 0 (no damage) to 100 (full damage)
Tyre wear multiplier in percent: 0 = no tyre wear, 100 = realistic, higher values increase wear
The number of tyres allowed outside of track limits before a penalty is applied. -1 disables.

% level of grip at session start
Level of randomness added to the start grip
How much of the gained grip is to be added to the next session 100 -> all the gained grip.
