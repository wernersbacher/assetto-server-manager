sTracker Options

Server side plugin integration

sTracker is the popular server side app companion to pTracker, for lap and race tracking.

sTracker is not developed or maintained by the Server Manager authors. If you have questions related to the operation of the sTracker tool itself, please ask on the sTracker support thread.

Installation

STracker is not installed. Please follow the instructions below to install STracker, or contact your Server Administrator:

  1. Download stracker
  2. Extract the stracker zip into a folder called "stracker" (case sensitive) in your Assetto Corsa Server folder
  3. If you are on Linux, extract the stracker_linux_x86.tgz folder. (e.g. tar xfvz stracker_linux_x86.tgz)
  4. Make sure that you have set UDP Plugin Address and UDP Plugin Local Port in Server Options
  5. Refresh this page!
